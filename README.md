# Freelance Developer Portfolio

React + Vite + Tailwind CSS portfolio starter.

## Requirements
- Node.js (current LTS recommended)
- npm
- Git (for publishing)

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Verify production build
```bash
npm run build
npm run preview
```

## GitHub Pages deployment
1. Create a GitHub repository named `freelance-portfolio`.
2. Keep `base: '/freelance-portfolio/'` in `vite.config.js`.
3. Push the source branch to GitHub.
4. Run `npm run deploy`.
5. In repository Settings → Pages, select Deploy from a branch, `gh-pages`, `/(root)`.

## Personalize before publishing
- Replace `YOUR_EMAIL@example.com` in `src/App.jsx`.
- Replace the LinkedIn placeholder with your real profile URL.
- Verify listed skills and project descriptions.
- Add public project links/screenshots only when you have permission.
